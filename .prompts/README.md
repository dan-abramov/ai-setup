# Prompt Pack For HW-2

Каталог `.prompts/` содержит прайминг-промпты под типовые flow в проекте.

## Файлы

- `orient.md` — вход в проект и triage контекста.
- `spec.md` — подготовка/обновление feature-спеки.
- `implement.md` — реализация на основе feature + implementation plan.
- `review.md` — проверка diff и traceability до `REQ/EC/CHK`.
- `resume.md` — быстрый перезапуск сессии и next steps.
